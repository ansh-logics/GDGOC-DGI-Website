# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Instead, report the issue privately to the project maintainers with:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Suggested remediation, if available

We will review the report as quickly as possible and coordinate a responsible fix and disclosure process.

## Supported Versions

Security support is provided for the latest version on the default branch unless stated otherwise.
